# Name and logo policy

The source code of VIT-AP Student App is licensed under the GNU GPL,
version 3 (see `LICENSE` and `NOTICE`). That license covers the code. It
does not cover the project's identity:

- the name "VIT-AP Student App"
- the logo and app icons in `assets/images/logo/`, and the launcher icons
  generated from them under `android/` and `ios/`
- the package and bundle identifier `com.udhay.vitapstudentapp`

## Allowed without asking

- Saying that a fork or other project is based on VIT-AP Student App, or
  works with it, as long as that statement is accurate.
- Using the name in articles, reviews, tutorials and talks.
- Building and running the unmodified app from this repository for
  personal use.

## Not allowed

- Publishing a modified version under the name "VIT-AP Student App", or
  under a name or icon close enough to be confused with it.
- Using the logo or icons in a fork, in a store listing, or on a website
  for a different app.
- Publishing under the package or bundle identifier above.
- Suggesting that a fork is official, or that it is endorsed by this
  project's maintainers.

## Forks

Forks are welcome under the terms of the license. Before publishing one:

1. Choose a new name and a new icon.
2. Change the Android `applicationId`, the iOS bundle identifier and the
   app group identifiers.
3. Keep the attribution required by `NOTICE`, both in the app and in the
   README.
4. Use your own Firebase project, API keys and backend endpoints. The
   services this project runs are for its official builds only.

VIT-AP Student App is an independent project. It is not affiliated with,
or endorsed by, VIT-AP University.
